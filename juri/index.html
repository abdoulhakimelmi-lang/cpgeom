    📘 Aspects juridiques — Propriété intellectuelle¶

    🎯 Objectif du cours¶

    Comprendre :

    • Qui possède quoi
    • Qui a le droit d’utiliser / modifier / diffuser
    • Quelle protection s’applique (œuvre, base de données, etc.)

    ✅ ÉTAPE 1 — La notion d’« œuvre de l’esprit »¶

    🧠 Définition¶

    Une œuvre de l’esprit est une création originale réalisée par une personne physique.

    📌 Exemples :¶

    • Un texte (rapport)
    • Une carte mise en page (cartographie)
    • Un logo
    • Une photo
    • Un code (script Python)
    • Un design d’application

    ⚠️ Il n’est pas nécessaire que l’œuvre soit « belle » : elle doit simplement être originale (minimum de créativité).

    📍 Exemple SIG (chaussées)¶

    • Carte avec choix de couleurs, symboles, mise en page → ✅ œuvre protégée
    • Export brut sans choix particulier → originalité plus faible (mais souvent la mise en page suffit)

    ✅ ÉTAPE 2 — Le droit d’auteur¶

    Le droit d’auteur comprend :

    • 🔒 Le droit moral
    • 💰 Les droits patrimoniaux

    2.1 🔒 Le droit moral¶

    🧠 Définition¶

    Le droit moral protège le lien entre l’auteur et son œuvre.

    Il comprend :¶

    • Le droit d’être reconnu comme auteur
    • Le droit au respect de l’œuvre
    • Le droit de décider de publier ou non

    ✅ Caractéristiques¶

    • Ne peut pas être vendu
    • Reste attaché à l’auteur
    • Très protecteur en France

    📍 Exemple¶

    Si quelqu’un utilise ta carte et enlève ton nom → atteinte au droit moral.

    2.2 💰 Les droits patrimoniaux¶

    🧠 Définition¶

    Ils permettent d’exploiter l’œuvre :

    • Reproduire
    • Diffuser
    • Modifier
    • Vendre

    ✅ Caractéristiques¶

    • Peuvent être cédés par contrat
    • Souvent transférés à l’employeur ou au commanditaire

    📍 Exemple SIG¶

    Script Python réalisé dans le cadre professionnel → droits d’exploitation souvent détenus par l’administration (selon contrat).

    ✅ ÉTAPE 3 — La Propriété intellectuelle (PI)¶

    La propriété intellectuelle protège :

    • Les œuvres (droit d’auteur)
    • Les bases de données
    • Les marques et brevets (hors programme ici)

    Dans ce cours :
    ➡️ Droit d’auteur
    ➡️ Droit des bases de données

    ✅ ÉTAPE 4 — Le droit du producteur de base de données¶

    🧠 Définition¶

    Une base de données est protégée lorsqu’un investissement substantiel (temps, argent, moyens) a été réalisé pour la constituer.

    Le producteur est celui qui investit.

    🔒 Protection¶

    Il peut interdire :

    • L’extraction substantielle
    • La réutilisation massive
    • La copie importante

    📍 Exemple¶

    Base diagnostics chaussées construite sur 10 ans → protégée au titre du droit du producteur.

    ✅ ÉTAPE 5 — Les types d’œuvres¶

    5.1 🤝 Œuvre de collaboration¶

    Plusieurs personnes créent ensemble une œuvre.

    ➡️ Tous sont auteurs.

    Exemple :
    Application web SIG développée par deux agents.

    5.2 🧩 Œuvre composite¶

    Création nouvelle utilisant une œuvre existante.

    ➡️ Respect obligatoire des licences.

    Exemple SIG :

    • Fond IGN
    • Données OpenStreetMap
    • Contenu personnel

    Carte composite → respect des licences requis.

    5.3 🏢 Œuvre collective¶

    Créée sous la direction d’un organisme et publiée sous son nom.

    ➡️ L’organisation est souvent considérée comme titulaire des droits patrimoniaux.

    Exemple :
    Tableau de bord publié au nom d’une administration.

    ✅ Application au contexte professionnel (SIG)¶

    Dans un service public, les productions peuvent être :

    • Cartes
    • Dashboards
    • Scripts
    • Rapports
    • Bases structurées

    À retenir :¶

    • Une carte peut être une œuvre de l’esprit
    • Les droits patrimoniaux sont souvent détenus par l’administration
    • La base appartient au producteur (celui qui finance)
    • Les licences externes doivent être respectées

    📊 Tableau récapitulatif — Cas pratiques¶

    Situation Droit moral Droits patrimoniaux Producteur base
    Agent crée une carte Agent Administration Administration
    Prestataire crée une base Prestataire Selon contrat Celui qui finance
    Collaboration agent + prestataire Les deux Selon contrat Celui qui investit
    Base construite sur 10 ans Pas forcément œuvre Organisation Organisation
    Carte livrée par prestataire Prestataire Si cession → commanditaire Financeur

    🎯 Cas type examen¶

    Cas 1¶

    Prestataire réalise une base diagnostics.

    • Droit moral → prestataire
    • Droits patrimoniaux → selon contrat
    • Producteur → financeur

    Cas 2¶

    Agent crée un dashboard.

    • Droit moral → agent
    • Droits patrimoniaux → administration
    • Producteur base → administration

    🧠 Les 3 phrases essentielles¶

    1. Le droit moral reste attaché à la personne physique qui a créé l’œuvre.
    2. Les droits patrimoniaux peuvent être cédés par contrat.
    3. Le droit du producteur protège l’investissement substantiel réalisé pour constituer une base de données.

    📝 Résumé ultra court¶

    Notion À retenir
    Œuvre de l’esprit Création originale
    Droit moral Toujours à l’auteur
    Droits patrimoniaux Peuvent être transférés
    Producteur base Celui qui investit

    🎤 Phrase intelligente à dire en examen¶

    Le droit moral protège l’auteur, les droits patrimoniaux encadrent l’exploitation et le droit du producteur protège l’investissement réalisé pour constituer une base de données.
